Write a program that will scan a file "fruit.txt". Each line contains one fruit and we should output the fruit occurrences
in descending order based on their frequency. Should fruit have the same counts they should be sorted alphabetically.

Example:

Apple
Banana
Apple
Orange
Banana
APPLE
pear
PEAR

should output:
apple: 3
banana: 2
pear: 2
orange: 1
